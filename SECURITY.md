# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/giggly9990/ravenseed/security/advisories/new). Do not open a public issue.

Include the RavenSeed version (`ravenseed version`), how it is deployed and the steps to reproduce. Redact API keys, passkeys and tracker download links.

## Supported versions

Fixes go into the latest release only.

## Deployment guidance

See [deployment and data protection](docs/security.md) for network exposure, authentication, reverse proxies and stored data.
